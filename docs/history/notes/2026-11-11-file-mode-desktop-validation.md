# File workflow desktop validation

Tested the isolated Windows dev app with five-second, 48 kHz, 16-bit mono and stereo WAV fixtures. The stable app and its data were not used. Local evidence is under the worktree's ignored `artifacts/file-mode-history/` directory.

| Check                 | Observation                                                                                                                                                                                                                                                                     |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Startup               | Welcome and crash-report prompts appeared separately. Welcome choices persisted across a full restart. No crash report was submitted.                                                                                                                                           |
| Transport and summary | Compared Live Ready before and after. File Result retained the shared transport layout. At 431 CSS pixels the result time remained readable and the summary used its overflow count.                                                                                            |
| File details          | Clicking the detail icon pinned the popover; Escape closed it. Automated coverage also exercises the hover preview.                                                                                                                                                             |
| Snapshot              | Selected a point two seconds before the end, then cleared it and confirmed that the same file remained active in File mode.                                                                                                                                                     |
| Source replacement    | Replaced a stereo fixture with a mono file at the same path and reanalyzed the background entry. Both results remained available and the active file did not change.                                                                                                            |
| Reports               | Saved Markdown and JSON reports from the running app. Reports use the complete result and the Profile active at export.                                                                                                                                                         |
| Statistics CSV        | Saved a combined export through the native Windows save dialog. A separate CSV reader confirmed two rows and 90 columns, numeric channel peaks and times, empty second-channel fields for mono, parseable Profile rules and verdicts, one export timestamp, and no local paths. |

The report and CSV changes write files only when requested. They add no data recipient or network transfer. Report metadata and CSV rows omit the source path.

The history budget was estimated separately; see [File history budget validation](2026-11-11-file-history-budget-validation.md). Automated tests exercise release and restoration under a reduced budget. Long-duration memory pressure in the desktop WebView, a full theme matrix, Excel import, and macOS and Linux desktop behavior were not measured here.
